<h1 align="center">Despacer</h1>

<p align="center">
  ターミナルで<b>Claude Code</b>や<b>Codex</b>の長いコマンドをコピーして、ひとつながりのままペーストできます。

**Claude Code**や**Codex**のように、ターミナルで動くAIコーディングエージェントは、長い行を自分で折り返します。長いコマンドの折り返しをターミナルに任せずに、本物の改行とインデントを出力の中に入れてしまうのです。そのため、iTermやTerminalからコマンドをコピーしてペーストすると、バラバラに分かれた状態で貼り付けられ、実行できません:

```
  curl --fail --location --retry 3 --connect-timeout 10 --max-time 120
  --output premail-demo.zip
  "https://example.com/downloads/premail/a-fictional-demo-with-a-deliberately
  -long-filename-for-testing-terminal-line-wrapping.zip"
```

Despacerは、この問題を解決する小さな無料のオープンソースのメニューバーアプリです。Despacerを実行しておけば、同じコピーが、本来あるべき1つのコマンドとしてペーストされます:

```
curl --fail --location --retry 3 --connect-timeout 10 --max-time 120 --output premail-demo.zip "https://example.com/downloads/premail/a-fictional-demo-with-a-deliberately-long-filename-for-testing-terminal-line-wrapping.zip"
```

- Terminal、iTerm2、Ghostty、Warp、kitty、Alacritty、WezTerm、Hyper、Tabby、Rioに最初から対応し、自分で追加したほかのアプリでも動作します
- 手を加えるのは、ターミナルが最前面にあるときにコピーしたテキストだけです
- ネットワーク通信なし、分析なし、データの収集なし
- macOS 14 Sonoma以降が必要です

## インストール

Despacerは現在、ソースからビルドしてインストールします。1分ほどで終わります。

1. Appleのコマンドラインツールがない場合は、インストールします:
   ```sh
   xcode-select --install
   ```
2. このリポジトリをクローンしてビルドします:
   ```sh
   git clone https://github.com/MattSenter/despacer.git
   cd despacer
   ./build.sh --install
   ```
   `Despacer.app`がビルドされ、アプリケーションフォルダにコピーされて、起動します。
3. 設定ウインドウが表示されます。**システム**で**ログイン時に開く**をオンにしておくと、Despacerがいつでも使える状態になります。

これで完了です。いつもどおりにClaude CodeやCodexからコマンドをコピーして、ペーストしてください。

## Despacerの使い方

新しく覚えることはありません。ターミナルでコマンドを選択してCmd+Cを押し、使いたい場所にペーストするだけです。ペーストするころには、Despacerがすでにコマンドを元どおりにつなぎ直しています。かかる時間はたいてい100分の数秒です。

- **ターミナルからのコピー**は確認され、必要なら修正されます。
- **ほかのアプリからのコピー**は一切見ません。
- **もともと分割されていないテキスト**（短いコマンドや通常のターミナル出力など）は、そのまま残ります。

修正が思いどおりでなかった場合は、メニューバーのアイコンから**最後の修正を取り消す**を選ぶと、コピーした内容がコピーしたときのままの状態に戻ります。**修正**にある**最近の修正**のリストには直近10件の修正が表示され、それぞれに**元のテキストをコピー**と**修正後をコピー**のボタンがあります。

## 設定

設定ウインドウを開くには、アプリケーションフォルダ（またはSpotlightやLaunchpad）からDespacerを開くか、メニューバーのアイコンから**設定…**を選びます。サイドバーには7つのパネルがあります: **修正**、**ターミナル**、**システム**、**アクセス許可**、**プライバシー**、**その他のプロジェクト**（同じ開発者のほかのアプリ）、**情報**（バージョン情報とリンク）。

| 設定 | パネル | 内容 |
|---|---|---|
| **ターミナルのコピーを修正** | 修正 | Despacerを終了せずにオン/オフを切り替えます。 |
| **セッション履歴と照合** | 修正 | お使いのコンピュータ上のClaude CodeとCodexのセッションファイルから、正確な元のテキストを探します。デフォルトでオンです。スイッチの下に、それぞれのアプリの履歴が見つかったかどうかが表示されます。 |
| **ほかの折り返されたテキストも修復** | 修正 | 完全一致が見つからないときに、ターミナルの幅で明らかに折り返された行をつなぎ直します。デフォルトでオンです。 |
| **サウンドを再生** | 修正 | 修正したコピーをペーストできる状態になると、短いサウンドを再生します。デフォルトでオフです。 |
| **標準** | ターミナル | Despacerが最初から認識しているターミナルで、すべてデフォルトでオンです。Despacerに監視させたくないものはチェックを外してください。 |
| **自分で追加** | ターミナル | ターミナルを内蔵したコードエディタなど、コマンドをコピーするほかのアプリです。**アプリを追加…**をクリックして選びます。 |
| **ログイン時に開く** | システム | ログイン時にDespacerを自動的に起動します。このウインドウは開かず、静かに起動します。 |
| **メニューバーに表示** | システム | メニューバーのアイコンを表示または非表示にします。オフにすると、Despacerは見えない状態で動作します。このウインドウに戻るには、アプリケーションフォルダからDespacerを開きます。 |
| **Despacerを終了** | システム | アプリを本当に終了します。ウインドウを閉じても（またはCmd+Qを押しても）ウインドウが閉じるだけで、Despacerは実行され続けます。 |

**アクセス許可**パネルには、macOSがDespacerにコピーした内容の読み取りを許可しているかどうかが表示されます（[トラブルシューティング](#トラブルシューティング)を参照）。設定は自動的に保存され、すぐに反映されます。

## メニューバーのメニュー

メニューバーのDespacerアイコンをクリックすると、すばやくアクセスできます:

- **ターミナルのコピーを修正**: Despacerのオン/オフを切り替えます。
- **修正時にサウンドを再生**: **修正**にあるスイッチと同じです。
- **最後の修正を取り消す**: 最後に修正したコピーを、コピーしたときのままの状態でクリップボードに戻します。
- **メニューバーに表示**: チェックを外すとアイコンが消えます。Commandキーを押しながらアイコンをメニューバーの外にドラッグして消すこともできます。
- **ログイン時に開く**: ログイン時にDespacerを起動します。
- **設定…**: 設定ウインドウを開きます。
- **Despacerを終了**: アプリを終了します。

## キーボードショートカット

Despacerの設定ウインドウが最前面にあるとき:

| ショートカット | 内容 |
|---|---|
| Cmd+W | 設定ウインドウを閉じます。Despacerは実行され続けます。 |
| Cmd+Q | こちらもウインドウを閉じるだけで、Despacerは実行され続けます。うっかりCmd+Qを押してもオフになりません。本当に終了するには**Despacerを終了**を使います。 |
| Cmd+H | ほかのアプリと同じようにDespacerを非表示にします。 |
| Cmd+, | 設定を開きます。 |

## トラブルシューティング

**コピーしたものが、まだ分割されたままペーストされます。**
Despacerが実行中であること（アプリケーションフォルダから開いてください）と、**ターミナルのコピーを修正**がオンになっていることを確認してください。お使いのターミナルが**ターミナル**でチェックされているかを確認し、なければ**アプリを追加…**で追加してください。そのうえで、**アクセス許可**パネルを確認してください。

**Despacerがほかのアプリからペーストしてよいか、macOSに確認されました。**
新しいバージョンのmacOSでは、コピーした内容を読み取れるアプリを自分で決められます。**許可**を選んでください。**許可しない**を選んだ場合は、「システム設定」>「プライバシーとセキュリティ」>「他のAppからペースト」を開き、Despacerを「許可」に設定してください。**アクセス許可**パネルには現在の設定が表示され、その画面に移動するボタンもあります。

**つなげるべきでないコピーがつながってしまいました。**
メニューバーのアイコンから**最後の修正を取り消す**を選んでください。セッション履歴との完全一致なら改行を間違えることはありませんが、一致が見つからないときは、折り返しルールが推測するしかありません。何度も起こる場合は、**ほかの折り返されたテキストも修復**をオフにして、セッション履歴で見つかったものだけをDespacerに修正させてください。ルールを改善できるよう、コピーしたテキストを添えて[Issueを作成](https://github.com/MattSenter/despacer/issues)してください。

**通常のターミナル出力からコピーしたものを、Despacerが変更してしまいました。**
Despacerが修復するのは、Claude CodeとCodexが出力する2スペースのインデントがあるテキストか、それらのセッション履歴に一字一句同じものが見つかったテキストだけです。それ以外のものをコピーして変更された場合は、[Issueを作成](https://github.com/MattSenter/despacer/issues)してください。

**メニューバーのアイコンをオフにしたら、Despacerが見つかりません。**
アプリケーションフォルダからDespacerを開いてください。設定ウインドウが表示されるので、**システム**でアイコンを再びオンにできます。

**「ログイン時に開く」がオンのままになりません。**
macOSでは、決まった場所にあるアプリしかログイン時に開けません。Despacerがアプリケーションフォルダにあることを確認してから（`./build.sh --install`を使えばそこに入ります）、もう一度設定をオンにしてください。

## 仕組み

Claude CodeとCodexはどちらも出力を自分で描画し、どちらも長い行をターミナルの幅に合わせて折り返してから出力します。本物の改行を入れ、続けて2スペースのインデントを入れるのです。ターミナルには別々の行しか届かないので、コピーされるのも別々の行です。元の行末はターミナルにまったく届かないため、ターミナル側の設定でこれを元に戻すことはできません。

Despacerはクリップボードを1秒に20回確認します（macOSにはクリップボードの通知がなく、この確認の負荷はほぼゼロです）。コピー元がターミナルアプリなら、2つのステップで修正します:

1. **折り返しルール（即時）。** 2スペースのインデントと行末の余白を取り除き、折り返しによって生じた改行をすべてつなぎ直します。次の単語が上の行に収まらなかった場合、その改行は折り返しとみなされます。幅いっぱいまで埋まった行は単語の途中で分割されていますが、それは単語が1行に収まらないほど長いときだけなので、スペースを入れずにつなぎます。それ以外の改行と、`\`で終わる行はそのまま残ります。このバージョンはすぐにクリップボードに入るので、ウインドウを切り替えるより先に準備が整います。
2. **完全一致（少しあとで）。** バックグラウンドで、コピーしたテキストを、スペースと改行をすべて無視して、Claude Code（`~/.claude/projects`）とCodex（`~/.codex/sessions`）がお使いのコンピュータに保存しているセッションファイルから探します。直近1日以内にアクティブだったセッションを、新しいものから順に確認します。一致するものが見つかると、エージェントが書いたとおりの元のテキストをクリップボードに入れます。ただし、その間にほかのものをコピーしていた場合は入れません。

ほとんどのコマンドは折り返しルールだけで正しく直りますが、行の途中から始まる選択範囲のように、どうしても見分けられない改行もあります。そうしたケースは完全一致で解決します。選択範囲がどこから始まり、どこで終わっても機能します。

アプリ本体は[`App/`](App)にある1,400行未満のSwiftコードで、修正エンジンは[`Sources/DespacerCore/`](Sources/DespacerCore)にある約250行のコードと、そのテストです。

## コマンドラインツール

同じ修正エンジンは、コマンドラインのフィルタとしても使えます。スクリプトで使ったり、すでにどこかにペーストしたテキストを修正したりするのに便利です:

```sh
swift build -c release
pbpaste | .build/release/despacer | pbcopy
```

`--explain`を付けるとどの方法を使ったかが表示され、`--no-transcripts`を付けると折り返しルールだけを使います。

## アンインストール

1. メニューバーのアイコン、または設定ウインドウの**システム**パネルから**Despacerを終了**を選びます。
2. **ログイン時に開く**をオンにしていた場合は、先にオフにするか、「システム設定」>「一般」>「ログイン項目」でDespacerを削除します。
3. `/Applications/Despacer.app`をゴミ箱にドラッグします。
4. 必要に応じて、設定も削除します:
   ```sh
   defaults delete com.mattsenter.Despacer
   ```

## ビルドと貢献

```sh
./build.sh            # builds build/Despacer.app (ad-hoc signed)
./build.sh --install  # also copies it to /Applications and opens it
swift test            # runs the fixing engine's tests
swift Tools/make-icon.swift   # regenerates the app icon in Resources/
python3 scripts/check-localization.py   # checks every language is complete
```

Despacerは、英語、ドイツ語、スペイン語、フランス語、日本語、韓国語、ブラジルポルトガル語、簡体字中国語、繁体字中国語で提供しています。アプリに表示する新しい文字列は、`Localization/en.lproj/Localizable.strings`とほかのすべての`.lproj`に追加してください。このREADMEや`PRIVACY.md`を変更した場合は、それぞれの翻訳にも反映してください。

| パス | 内容 |
|---|---|
| `Sources/DespacerCore/` | 修正エンジン: 折り返しルール（`Despacer.swift`）とセッション履歴の照合（`TranscriptMatcher.swift`） |
| `Tests/DespacerCoreTests/` | 実際に分割されたコピーをもとに作ったテスト |
| `Sources/despacer/` | コマンドラインツール |
| `App/main.swift` | アプリのデリゲートとメニュー |
| `App/ClipboardWatcher.swift` | クリップボードを監視して修正を適用 |
| `App/TerminalApps.swift` | 標準のターミナルと、自分で追加したアプリ |
| `App/SettingsView.swift` | SwiftUIの設定ウインドウ: サイドバーとパネル |
| `App/OtherProjectsView.swift`, `Resources/other-projects/` | 「その他のプロジェクト」パネルとそのスクリーンショット |
| `App/BuiltByCredit.swift`, `App/OutboundLink.swift` | サイドバーのクレジットと著作権表示、タグ付きの外部リンク |
| `App/MenuBarIcon.swift` | コードで描画するメニューバーのアイコン |
| `Localization/<lang>.lproj/` | 各言語のアプリの文字列（英語がソース） |
| `README.<lang>.md`, `PRIVACY.<lang>.md` | 翻訳されたドキュメント |
| `scripts/check-localization.py` | 文字列やドキュメントが欠けている言語があると失敗します |
| `Tools/make-icon.swift` | アプリアイコンを描画します |

IssueやPull Requestを歓迎します。特に、折り返しルールが正しく直せなかった分割コピーの報告をお待ちしています。
