# Datenschutzerklärung für Despacer

[English](PRIVACY.md) · **Deutsch** · [Español](PRIVACY.es.md) · [Français](PRIVACY.fr.md) · [日本語](PRIVACY.ja.md) · [한국어](PRIVACY.ko.md) · [Português (Brasil)](PRIVACY.pt-BR.md) · [简体中文](PRIVACY.zh-Hans.md) · [繁體中文](PRIVACY.zh-Hant.md)

Zuletzt aktualisiert: 22. Oktober 2026

Despacer erfasst keine Daten. Gar keine.

- Es baut keine Netzwerkverbindungen auf.
- Es gibt kein Konto, keine Analysen, keine Absturzberichte, keine Werbung und kein Tracking.
- Es liest die Zwischenablage nur direkt nachdem du etwas kopiert hast, während eine Terminal-App (eine, die in seinen Terminals-Einstellungen aufgeführt ist) im Vordergrund ist. Kopien aus allen anderen Apps werden nie gelesen.
- Um das exakte Original eines kopierten Befehls zu finden, liest es die Sitzungsdateien, die Claude Code und Codex auf deinem Computer ablegen (`~/.claude/projects` und `~/.codex/sessions`). Es liest sie nur. Es verändert, kopiert oder überträgt sie nie. Du kannst das mit **Mit Sitzungsverlauf abgleichen** ausschalten.
- Es behält deine letzten zehn Korrekturen im Arbeitsspeicher, damit du sie widerrufen kannst. Sie werden nie auf die Festplatte geschrieben und sind gelöscht, sobald Despacer beendet wird.
- Seine Einstellungen (welche Funktionen eingeschaltet sind, welche Apps als Terminals gelten, In der Menüleiste anzeigen, Bei der Anmeldung öffnen) werden nur auf deinem Computer gesichert.

Falls sich daran jemals etwas ändert, steht es zuerst auf dieser Seite.

Fragen: Erstelle ein Issue unter https://github.com/MattSenter/despacer/issues.
